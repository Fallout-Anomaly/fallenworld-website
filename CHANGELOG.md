# Knox Aftermath Changelog

## 2026-08-28 - Server configuration update

The current server configuration has been expanded with new quality-of-life,
survival, faction, map, vehicle, inventory, and atmosphere content. The additions below
are linked directly to their Steam Workshop pages and use the current Steam
preview image for each item.

<details>
<summary>Server rules and settings</summary>

- Death announcements are enabled.
- Blood effects remain for three in-game days.
- New factions can be created after seven survived days.
- Player collision is enabled.
- Safehouses do not allow fire or trespassing, but do allow respawn.
- Sledgehammers are restricted to safehouse areas.
- Sleep is required for survivors.
- The Steam scoreboard is enabled.
- Trash cleanup is enabled.
- Faction war is enabled.
- Extraction Mode has been added to the configured map list alongside the Arcadia RV interior map and Muldraugh, KY.

</details>
